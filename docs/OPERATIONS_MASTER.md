# Operations Master

Operations describe what should happen. Work Centers describe where a class of work happens. Production Resources identify the executable equipment within a Work Center.

Canonical operation codes are stable uppercase values such as PICKING, DTG_PRINT, UNDERPRINT, PUTWALL, SCREEN_PRINT, UV_PRINT, QC, PACKING and DISPATCH. Oracle queue and location codes are not canonical operations.

Resource asset links are nullable and future-safe; Phase A does not tightly couple production resources to Maintenance assets.
